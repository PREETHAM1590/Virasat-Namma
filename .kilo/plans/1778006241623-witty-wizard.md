# Virasat Firebase Migration & Screen Verification Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the Virasat Android app from Room local database to Firebase Firestore backend, ensuring all 8 existing screens remain functional, build cleanly, and are verified screen-by-screen.

**Architecture:** Preserve existing MVVM + Repository pattern. Introduce `HeritageRepository` interface with two implementations: `RoomHeritageRepository` (kept as baseline fallback) and `FirebaseHeritageRepository` (new Firestore-backed). A `RepositoryProvider` switches between them at runtime.

**Tech Stack:** Kotlin 2.0, Jetpack Compose, Material 3, Firebase BOM (Firestore, Auth), KSP, Coil, ML Kit, CameraX
